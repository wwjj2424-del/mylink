# 마이링크 (MyLink) 기획 문서

## 1. 프로젝트 개요
- **프로젝트명:** 마이링크 (MyLink)
- **목적:** 여러 개의 링크를 한 페이지에 모아 공유한다.
- **대상:** SNS 사용자, 크리에이터, 포트폴리오를 공유하려는 학생
- **배포 주소:** https://wwjj2424-del.github.io/mylink/MyLink/

## 2. 기능 목록

| 구분 | 기능 | 상태 |
|---|---|---|
| 필수 | 프로필 표시 (사진, 이름, 사용자 이름, 소개) | 완료 |
| 필수 | 링크 목록 표시 (아이콘, 제목, 새 탭으로 열기) | 완료 |
| 필수 | 링크 추가 / 수정 / 삭제 (CRUD) | 완료 (브라우저 저장) |
| 필수 | 클릭 통계 (총 클릭수, 링크별 클릭수) | 완료 (브라우저 저장) |
| 선택 | 공유 미리보기 (OG 태그, 미리보기 이미지) | 완료 |
| 선택 | 반응형 디자인, 다크 모드 | 완료 |
| 선택 | 404 페이지 | 완료 |
| 이후 | 구글 로그인, 서버 저장(Firebase), 개인 URL(/username) | 계획 |

## 3. 상세 기능 정의

### 링크 추가
- **입력:** 제목, 주소(URL), 아이콘
- **동작:** [추가] 버튼을 누르면 목록 맨 아래에 추가하고 "NEW" 표시를 붙인다.
- **성공:** 입력 칸을 비운다.
- **예외 처리:** 실패하면 입력값은 그대로 두고 아래 문구를 빨간색으로 보여준다.
  - 제목이 비었을 때: "제목을 입력해주세요"
  - 주소가 비었을 때: "주소를 입력해주세요"
  - 주소 형식이 틀렸을 때(http/https가 아님): "올바른 주소를 입력해주세요"

### 링크 수정 (인라인 편집)
- 연필 버튼을 누르면 그 자리에서 제목, 주소, 아이콘을 입력 칸으로 바꾸고 기존 값을 채운다.
- [저장]은 링크 추가와 같은 검사를 거친 뒤 반영하고, [취소]는 원래 값으로 돌아간다.

### 링크 삭제
- 휴지통 버튼을 누르면 확인 창을 띄운다.
  - 제목: "정말 삭제하시겠습니까?"
  - 내용: "[링크 이름]" 링크가 삭제됩니다.
  - 경고: 삭제한 링크는 되돌릴 수 없어요.
  - 버튼: [취소](회색, 왼쪽) [삭제하기](빨간색, 오른쪽)

### 클릭 통계
- 링크를 누르면 그 링크의 클릭수를 1 늘린다.
- 총 클릭수를 크게 보여주고, 링크별 클릭수를 많은 순으로 막대와 함께 보여준다.

## 4. 비기능 요구사항
- 모바일(360~767px)은 너비 100%에 좌우 여백 16px, 태블릿(768~1023px)은 너비 80%(최대 480px), 데스크탑(1024px 이상)은 400px로 고정한다.
- 버튼과 링크의 누르는 영역은 44px 이상으로 한다.
- 데이터는 브라우저(localStorage)에 저장한다. 로그인과 서버 저장은 이후 단계에서 Firebase로 바꾼다.

## 5. 사용자 시나리오
- **방문자:** 방문자는 친구의 관심사를 알기 위해 마이링크 주소를 연다. 프로필을 보고 링크 목록에서 원하는 링크를 눌러 해당 사이트로 이동한다.
- **관리자(본인):** 본인은 새 블로그를 알리기 위해 [내 링크 관리] 페이지에 들어간다. 제목과 주소를 입력해 링크를 추가하고, 오래된 링크는 수정하거나 삭제한다. 통계에서 어떤 링크가 많이 눌렸는지 확인한다.
