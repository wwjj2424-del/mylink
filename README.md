# 마이링크 (MyLink)

AI 코딩으로 만든 개인 링크 관리 페이지

## 프로젝트 소개
링크트리처럼 여러 링크를 한 페이지에 모아서 공유할 수 있는 페이지입니다.
'아이디어를 현실로 - 바이브 코딩' 과정에서 AI 도구를 활용하여 제작했습니다.

## 배포
Live Demo: https://wwjj2424-del.github.io/mylink/MyLink/

## 주요 기능
- 프로필 영역 (이름, 소개)
- 링크 목록 (새 탭으로 열기)
- 클릭 통계 (링크별 클릭 수 표시, 브라우저에 저장)
- 반응형 디자인 / 다크 모드
